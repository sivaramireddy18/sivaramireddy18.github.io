CM33 + CM55 Heterogeneous MCU

Design and validation of an ARM-based embedded system for real-time sensor acquisition, processing and response.

PortfolioFull projectGitHub

Problem & engineering objective

Modern embedded workloads need both deterministic control and higher computational throughput. This project separates those responsibilities: CM33 manages acquisition/control while CM55 performs computationally intensive sensor processing. The objective is to measure whether this heterogeneous split improves timing and throughput after IPC overhead is included.

Inputs

ADC/I²C/SPI sensor samples and timing events.

Processing

Buffering, average/filtering and threshold decision.

Outputs

UART diagnostics and optional GPIO/actuator indication.

Metrics

Latency, throughput, integrity, lost samples and accuracy.

Architecture

SENSOR → ADC / I²C / SPI → CM33 │ ▼ Timer + NVIC control │ ▼ IPC / SHARED MEMORY │ ▼ CM55 │ Sensor processing / decision │ ▼ IPC / SHARED MEMORY │ ▼ CM33 → UART / GPIO

The target MCU is represented generically. Public PSoC Edge architecture is used only as a reference; confidential registers, memory maps, part numbers and unpublished performance are excluded.

Firmware design

CM33

  • Timer/SysTick scheduling
  • ADC acquisition
  • Fixed 16-sample buffering
  • NVIC interrupt handling
  • IPC transmit/receive
  • UART diagnostics

CM55

  • Packet validation
  • Sensor block processing
  • Arithmetic mean calculation
  • Configurable threshold decision
  • Processing-time measurement
  • Result returned through IPC

Implementation roadmap

  1. CM33 boot + UART.
  2. CM55 startup.
  3. Deterministic IPC handshake.
  4. 16-sample packet transfer.
  5. ADC integration.
  6. Timer/SysTick + NVIC.
  7. CM55 processing + result return.
  8. Timestamping and performance measurement.
  9. Functional and negative validation.
  10. Capture evidence for final report.
