Embedded System Design

Situated Learning • 2026–27

Design and validation of a generic Cortex-M33 + Cortex-M55 heterogeneous ARM-based embedded system for real-time sensor processing.

Architecture

Sensor → ADC → CM33 → IPC/shared memory → CM55 → processing → IPC/shared memory → CM33 → UART/output.

Objectives

  • ADC-based sensor acquisition
  • Timer/SysTick and NVIC interrupt handling
  • CM33 ↔ CM55 IPC and shared-memory exchange
  • CM55 sensor processing
  • UART validation output
  • Single-core vs heterogeneous performance measurement

Validation

Measure acquisition time, IPC latency, CM55 processing time, end-to-end latency, throughput, data loss and accuracy. Actual measurements will replace placeholders before academic submission.

Implementation

Generic source package: CM33 acquisition/control, CM55 processing, common protocol/shared memory and hardware-abstraction layer.

Confidentiality

Public PSoC Edge architecture is used only as a reference. Confidential target-MCU part numbers, registers, memory maps and unpublished performance data are not included.
