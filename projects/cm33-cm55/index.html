Cortex-M33 + Cortex-M55 Heterogeneous MCU

System validation project for real-time sensor processing on a next-generation heterogeneous ARM MCU.

ProfileGitHub profile

Project objective

Evaluate a heterogeneous architecture in which CM33 handles system control and sensor acquisition while CM55 handles computationally intensive sensor processing. The design measures the real cost and benefit of offloading work across the two processors.

CM33
Acquisition, control, interrupts, IPC, diagnostics
CM55
High-performance sensor processing
IPC
Shared-memory packet exchange
Validation
Latency, throughput, integrity, accuracy

Architecture

Sensor → ADC → CM33 → IPC / Shared Memory → CM55 ↓ Sensor processing / decision ↓ IPC / Shared Memory → CM33 ↓ UART / GPIO / Output

Illustrative architecture. Confidential target-MCU registers, memory maps, part numbers and unpublished measurements are intentionally omitted.

Firmware flow

  1. Timer/SysTick schedules sampling.
  2. CM33 handles ADC acquisition and builds a fixed sample block.
  3. CM33 publishes a versioned packet and signals CM55.
  4. CM55 validates the packet, computes the sample average and threshold decision.
  5. CM55 returns a result packet.
  6. CM33 reports the result through UART and records timing/error counters.

Performance model

Compare CM33-only processing against CM33→IPC→CM55→IPC→CM33. The heterogeneous path must include communication overhead; it is not assumed to be faster.

Improvement (%) = ((T_single − T_heterogeneous) / T_single) × 100
